# Companion animation assets — 16/11/2026

Generated using the built-in image generation tool; no external API or CLI fallback. Canonical references are the four existing companion images. Original sheets are saved under `assets/source/companions/*-sheet-v1.png`; aligned PNG frames under the corresponding `*-frames/` directories. Runtime assets are `apps/game-client/public/art/companions/animated/*-v1.webp` and matching `*-still-v1.webp` files.

Each character has 16 authored keyframes: 8 idle/blink frames and 8 accent frames. Runtime uses variable frame holds and independent delays rather than adding duplicate frames to meet the plan's initial 16+8 estimate. Every atlas is 1024×1024, 4×4 cells of 256×256, contact at (128,238). One uniform scale per sequence; transparent noise outside the main subject was removed and the lower contact point aligned. No character content was redrawn during packaging. The four atlases total 1,376,568 bytes (~1.31 MiB), ~16 MiB decoded RGBA, excluding stills/background. QA report and animated GIF previews are in `docs/previews/companion-animation/`.

`scripts/package-companion-animation.py` reproduces packaging from the retained source sheets; unlike the generic composer it preserves the contact anchor instead of centering every frame independently. The original sprite design remains the reference; generated frame details show minor illustration variation, so playback uses restrained movements and holds.

The portrait background master is `assets/source/home-compact-v1.png`; delivery is `apps/game-client/public/art/home/compact-v1.webp` (900×1200). Compact layouts use a bounded crop to keep the companions on grass.
